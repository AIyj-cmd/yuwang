# CLAUDE_FRONTEND_PROMPT.md

请你先阅读并严格遵守：

```txt
docs/CLAUDE_FRONTEND_CONSTRAINTS.md
```

你只负责 yuwang 项目的前端视觉优化，不要修改后端代码、数据库结构、API 接口路径、请求参数、响应字段、鉴权逻辑和权限判断。

## 本次任务目标

1. 优化网站整体视觉效果；
2. 保留像素风格；
3. 将原左侧导航栏调整为顶部导航栏；
4. 优化页面内容设计、排版、布局；
5. 提升按钮、卡片、表单、标题、空状态、错误状态、加载状态的展示效果；
6. 做好桌面端、平板端和移动端适配；
7. 不破坏现有功能和接口调用；
8. 不重做管理后台，只允许小幅视觉统一。

## 顶部导航要求

1. 顶部导航是普通用户主要入口；
2. 核心入口可以直接展示；
3. 次级入口可以放入“更多”；
4. 账号相关入口可以放入用户菜单；
5. 管理后台入口只允许 admin 状态展示；
6. 移动端必须有折叠菜单或等效方案；
7. 不允许删除现有路由；
8. 不允许让导航挤爆；
9. 当前页面必须有高亮状态；
10. 导航不能遮挡页面内容。

## 视觉方向

1. 年轻化；
2. 像素风；
3. 有互联网抽象感；
4. 有一点游戏 UI 感；
5. 可以适度有梗；
6. 电影感、动漫感只能作为局部氛围；
7. 不要变成企业官网；
8. 不要变成普通 SaaS 后台；
9. 不要把首页改成纯营销落地页；
10. 第一屏仍要直接展示可操作产品能力。

## 禁止修改

1. 后端代码；
2. 数据库；
3. API 路径；
4. API 请求参数；
5. API 响应字段；
6. 鉴权逻辑；
7. 权限判断逻辑；
8. Fish Power Score 计算规则；
9. 内容审核规则；
10. 管理后台权限逻辑；
11. 写死假数据；
12. 删除现有功能；
13. 把通知、搜索、分享卡、个人画像、小组目标做成假数据展示。

## 验证命令

完成后至少运行：

```bash
npm run typecheck
npm run build
```

并手动检查：

1. 首页；
2. 结果页；
3. 排行榜；
4. 个人主页；
5. 通知中心；
6. 社区页；
7. 公开分享页；
8. 工会、圈子、小组入口；
9. 移动端顶部导航；
10. 管理后台登录与普通用户不可见状态。

## 输出要求

完成后请输出：

1. 修改了哪些前端文件；
2. 修改了哪些页面或组件；
3. 左侧导航如何改成顶部导航；
4. 哪些入口放在顶部主导航；
5. 哪些入口放在更多菜单或用户菜单；
6. 哪些地方优化了视觉层级；
7. 哪些地方优化了文案；
8. 是否做了移动端适配；
9. 是否影响接口调用；
10. 是否修改后端代码；
11. 如何运行项目查看效果；
12. 是否还有未完成事项。
